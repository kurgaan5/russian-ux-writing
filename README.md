# UX-копирайтинг v2

**Ivan Okulovsky** · идентификатор скилла: `ux-copywriting-v2`.

Текущая вторая версия скилла для написания, редактуры и проверки русских интерфейсных текстов. Помогает человеку понять ситуацию и доступное действие, сохраняя факты, ограничения и принятые термины продукта.

## Что изменилось во второй версии

- 127 проверок в 13 группах с критериями, примерами и учётом покрытия.
- 20 разборов «плохо → хорошо» и метод редактуры по образцам: сначала варианты текста, затем проверка.
- Отдельные режимы проверки готового текста и написания или прямой редактуры.
- Проверка смысловых связок целиком: заголовок, пояснение и действие.
- Учёт всех строк области, прочитанных материалов, непроверенных фактов и ограничений визуальной проверки.

Версия создана заново по источникам, описанным в [карте материалов](references/source-map.md). Название репозитория сохранено; идентификатор первой версии был `russian-ux-writing`, текущей — `ux-copywriting-v2`.

## Режимы работы

**Проверка — review.** Скилл проверяет готовый текст и предлагает исправления, улучшения и вопросы о неизвестных фактах. По умолчанию результат включает PNG со всеми замечаниями и публичный мини-сайт. Для этих артефактов нужны инструменты создания изображений и публикации сайта. Явно указанный пользователем формат результата имеет приоритет.

**Написание и прямая редактура — write.** Скилл создаёт или переписывает текст, сам проверяет его по реестру и выдаёт окончательную версию. Отчёт, карточки замечаний и сайт в этом режиме не создаются.

Реестр проверок применяется в обоих режимах. Скрипт контролирует полноту и согласованность учёта; качество формулировок и понятность для людей он не измеряет.

## Установка и использование

Поместите содержимое репозитория в каталог скилла `ux-copywriting-v2`:

```bash
git clone https://github.com/kurgaan5/russian-ux-writing.git "$HOME/.codex/skills/ux-copywriting-v2"
```

Если скилл уже установлен, обновите существующую копию. Для использования в другом агенте явно укажите путь к [SKILL.md](SKILL.md).

Проверка:

```text
Используй $ux-copywriting-v2. Проверь тексты в этой области макета.
Аудитория — … Задача человека — … Условия продукта — …
```

Написание:

```text
Используй $ux-copywriting-v2. Напиши заголовок, пояснение и кнопку
для этой ситуации. Факты и реальное действие — …
```
