# UX-копирайтинг

**Ivan Okulovsky** · идентификатор скилла: `russian-ux-writing`.

Версия **1.1.0**: контекстное ревью макета и единая визуальная выдача. Предыдущая версия сохранена в истории репозитория; эта редакция публикуется отдельной веткой `versions/v1.1.0`.

Скилл для грамотного, естественного и понятного русского текста в интерфейсах, на сайтах, в презентациях и отчётах. Помогает писать и редактировать с учётом задачи читателя, сохраняя факты, условия, терминологию и существенные оговорки.

## Что умеет

- Интерфейсы: кнопки, формы, подсказки, ошибки, пустые состояния, фильтры, оплата и уведомления.
- Страницы сайтов: связный текст, понятная структура, объяснение условий и следующий шаг.
- Презентации: ясный тезис, основание и существенная оговорка.
- Отчёты: связная аргументация, точные формулировки таблиц и сохранение исследовательской неопределённости.

Проверяет четыре слоя: русский язык, фактический смысл, стиль и соответствие носителю. Не удаляет двоеточия, тире и слова неопределённости по механическому правилу. Не определяет AI-авторство.

## Использование

Разместите пакет в каталоге скиллов агента под именем `russian-ux-writing` или явно укажите агенту путь к `SKILL.md`. Пример запроса:

```text
Используй $russian-ux-writing. Отредактируй этот текст для страницы сайта.
Сохрани условия и числа, убери канцелярит. Аудитория — …
Исходный текст: …
```

Для точного результата передайте исходные факты, место текста, аудиторию и реальные ограничения длины. Скилл редактирует формулировки; создание и визуальная проверка файлов презентаций, сайтов и отчётов требуют соответствующих инструментов.

Для наглядного отчёта по скриншоту сборщик создаёт один HTML-файл без внешних зависимостей:

```text
python scripts/build_review.py --review review.json --image screen.png --out review-v1.html
```

Схема JSON показана в `python scripts/build_review.py --help`. Все представления отчёта используют одинаковые ID и строки. Проверка отчёта не подтверждает, что предложенные строки помещаются в целевом интерфейсе.
